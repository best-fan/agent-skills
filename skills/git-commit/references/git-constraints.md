# Git 操作约束规范

本文档包含 Git 操作的约束规则、文件过滤规范和安全操作指南。

## Git 操作规范

### Commit 消息传递

使用 HEREDOC 格式传递 commit 消息，避免换行问题：

```bash
git commit -m "$(cat <<'EOF'
<type>(<scope>): <subject>

<body>

Authored-By: Claude Code AI
EOF
)"
```

### 文件添加规范

- ❌ **禁止使用** `git add -A` 或 `git add .`
- ✅ **必须使用** `git add <specific-files>` 明确指定文件

示例：
```bash
# 正确：明确指定文件
git add src/components/Button.tsx src/routes/home/Page.tsx

# 错误：添加所有文件
git add .
git add -A
```

### Hooks 规范

- ❌ **禁止使用** `--no-verify` 跳过 hooks
- ✅ **必须尊重** 项目配置的 pre-commit hooks

如果 hooks 失败：
1. 分析失败原因
2. 修复问题后重新提交
3. 不要绕过检查

### 强制推送规范

- ❌ **默认禁止** 使用 `--force` 强制推送
- ⚠️ **仅在用户明确要求并理解风险时** 可使用

使用 `--force` 的风险：
- 覆盖远程仓库的提交历史
- 可能丢失他人的工作成果
- 破坏团队协作流程

### 安全推送选项

优先使用安全选项：

```bash
# 推荐：仅当本地落后于远程时拒绝
git push --force-with-lease

# 比 --force 更安全
git push --force-if-includes
```

## 文件过滤规则

以下文件类型**默认不提交**（需用户明确指定才能提交）：

### 环境配置文件

| 文件 | 原因 |
|------|------|
| `.env` | 包含敏感环境变量 |
| `.env.local` | 本地环境配置 |
| `.env.*.local` | 特定环境配置 |
| `.env.development` | 开发环境配置 |
| `.env.production` | 生产环境配置 |

### 系统文件

| 文件 | 原因 |
|------|------|
| `.DS_Store` | macOS 系统文件 |
| `Thumbs.db` | Windows 系统文件 |
| `*.log` | 日志文件 |

### 依赖与构建产物

| 目录/文件 | 原因 |
|----------|------|
| `node_modules/` | npm 依赖目录 |
| `dist/` | 构建输出目录 |
| `build/` | 构建输出目录 |
| `.cache/` | 缓存目录 |
| `*.zip` | 压缩包文件 |
| `*.tar.gz` | 压缩包文件 |

### IDE 配置文件

| 文件 | 原因 |
|------|------|
| `.idea/` | IDE 配置 |
| `.vscode/`（部分） | 编辑器配置 |
| `*.swp` | Vim swap 文件 |

## 提交范围确认

### 强制确认项

1. **目标仓库确认**：必须先检查子仓库/子模块
2. **变更目录确认**：必须先展示变更目录概览
3. **拉取远程代码**：提交前必须同步远程状态

### 用户交互要求

- 使用 `AskUserQuestion` 进行所有关键决策确认
- 提供清晰的选项描述
- 支持用户自定义输入（"Other" 选项）

## 冲突处理流程

当拉取代码产生冲突时：

1. 运行 `git status` 查看冲突文件
2. 展示冲突文件清单（按目录分组）
3. 提示用户解决冲突
4. 用户确认解决后继续
5. 不自动解决冲突

### 冲突文件展示格式

```
冲突文件列表：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📁 src/components/
   └── 冲突: Button.tsx

📁 src/routes/
   └── 冲突: Page.tsx, index.module.scss
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
总计: 3 个冲突文件
```

## 异常情况处理

| 情况 | 处理方式 |
|------|----------|
| 无远程仓库 | 跳过拉取步骤 |
| 远程无新提交 | 跳过拉取步骤 |
| 拉取有冲突 | 提示用户解决 |
| Hooks 失败 | 分析原因，修复后重试 |
| Push 失败 | 检查权限和网络，询问用户 |
